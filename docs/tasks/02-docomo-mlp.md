# 2. ドコモMLP(通話録音)

**目的**: ドコモ回線での通話録音を本番導入するかの判断材料を揃える。

## フェーズ1 — ベンチマーク

- [ ] ドコモ回線1台を契約 — DoD: 実機で録音テスト可能な状態
- [ ] マスタ(会社名/担当名/電話番号)との紐付け検証 — DoD: 誰がどこと電話したか特定できるかYES/NO
- [ ] 通話内容が事業価値を持つか評価 — DoD: サンプル5件の所見レポート
- [ ] ドコモ契約条件の調査(プラン / 2年縛り有無 / 年額 / 現状比較) — 期限: 2026-04-22 / DoD: 表にまとまっている
- [ ] 実用化事例の情報収集 — DoD: 営業担当ヒアリングメモ

## フェーズ2 — 判断

- [ ] スモールスタート(1〜3台)か全面移行かを決定 — DoD: 決定と根拠が文書化
- [ ] 決定後の展開計画を作成

## メモ

- 起業論で横手・時津でテストして意味があるか懸念 → 実データ運用の方が早い可能性
- 「誰がいつどこと会話したか参照できる」だけでも勝ち
