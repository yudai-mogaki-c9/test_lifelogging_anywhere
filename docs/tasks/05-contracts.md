# 5. 契約・請求管理

**目的**: 突合・報告書フォーマット周りの人手作業をワークフロー化。担当変更の度に発生するメール往復をゼロに。

## 金額突合

- [ ] BP請求書 ↔ クライアント請求書の紐付けを全契約で確認 — DoD: 不一致ゼロ or 例外リスト
- [ ] 自社システム金額と実請求金額の一致チェックをワークフロー化 — DoD: 手動確認が不要

## 作業完了報告書

- [ ] システムで正しい担当者名を自動入力 — DoD: BPへの個別メール送信が不要
- [ ] 作業責任者の変更が発生した際の更新フロー整備

## オペレーション文書化

- [ ] 各作業の手順書を作成(担当変更しても回るレベル) — DoD: 引継ぎ演習で回ること
- [ ] 「中途半端開発のオペレーション未整備」ポイントを洗い出し

## メモ

- 現状は佐々木氏がメール対応で吸収している負荷を、システム側で吸収する方針
- 契約管理システム(F018等)は機能不足あり → 改修計画に連結
