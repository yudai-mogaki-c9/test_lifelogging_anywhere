# 6. ダッシュボード

**目的**: 営業・返信率・契約情報・通話録音を一元化し、BATを唯一の入口にする。

## 統合

- [ ] 返信率などの指標をBATダッシュボードに統合 — DoD: 1画面で俯瞰可能
- [ ] ギガカミを参照(読み取り)して「どの契約に関連するメールか」を表示 — DoD: 契約↔メール 紐付け表示
- [ ] ドコモ通話録音データをダッシュボードに取り込み — 前提: MLPフェーズ1完了
- [ ] 営業が毎日BAT経由で数字を入れる運用を定着 — DoD: 日次入力率

## 派生

- [ ] 受付等の分離機能の扱いを決定(統合 or 廃止)
- [ ] AI上司からダッシュボードへの書込API設計
