# トレイ常駐アプリ 試作スペック

> 「Macの右下に常駐、音声でタスク状況を入力、中長期DBへの書込と進捗管理まで全部やらせる」

## 目的

没頭を邪魔せず、発生した瞬間にタスクを捕まえる。報告のための報告を無くす。

## プラットフォーム

- macOS(社内標準)
- 実装候補: Electron + TypeScript、または Tauri(軽量)、または SwiftUI(ネイティブ)
- 試作は Electron + TS を推奨(Claude Codeで1時間プロトタイプ化しやすい)

## UI

- メニューバー(右上)常駐アイコン
- クリックでポップオーバー: [録音] [最近のタスク] [今日の予定]
- グローバルショートカット(例: ⌃⌥T)で即録音
- 録音停止で自動送信

## データフロー

1. 録音 → 文字起こし(Whisper API または ローカルwhisper.cpp)
2. 文字起こし → Claude に投げて構造化: {箱, タスク, 状態, 期限, 関連契約}
3. 構造化結果 → タスクDB(まずSQLite、後でWeb01に同居)
4. DB → 毎朝/18:00 のサマリ生成

## 最低限のコマンド

- `/report` — 今口頭で言った内容をタスクとして登録
- `/status <箱>` — その箱の未達/停滞を読み上げ
- `/done <タスクID>` — 完了マーク
- `/link <タスクA> <タスクB>` — 関連付け(営業↔ダッシュボード 等)

## 試作のゴール(1時間)

- 右下アイコン常駐
- クリックで録音開始/停止
- 文字起こし結果をローカルJSONに追記
- Claudeへのパイプは次段階

## 次段階

- Git活動の取り込み(コミットメッセージから該当タスクを自動で進捗更新)
- Teams/メール連携
- ダッシュボード(BAT)への表示統合
